# Simulador Master (prévia)

Site estático do **Dashboard Tributário, Performance & Governança Patrimonial**, publicado pelo GitHub Pages em https://melloni001.github.io/simulador-master/.

**Prévia:** os parâmetros legais, a tabela das UFs e a metodologia vieram do site original e aguardam conferência e assinatura de um planejador responsável. Nenhum resultado é parecer.

Os dados digitados ficam só no navegador de quem usa. Nada é enviado a servidor.

Este repositório contém apenas o resultado do build (`npm run build:pages`). O código-fonte fica em um repositório privado; não edite estes arquivos à mão.
